## Задание 2 

Для запуска сервиса:

```bash
docker-compose up -d --build
```

Генерируем телеметрию:
```bash
cd bionicpro-telemetry
pip3 install -r requirements.txt
python3 telemetry-gen.py       
```

Запускаем dag из airflow
http://localhost:8090 admin/admin

Логинимся и скачиваем отчет.
http://localhost:3000
